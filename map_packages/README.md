# Map packages

C++·Unreal·Python이 동일한 지도 기준을 사용하기 위한 버전형 데이터 경로다. 첫 패키지는 `wall_broad_v1/`로 구성한다.

패키지에 포함할 데이터:

- 기준 좌표계와 ENU 원점
- 도로·차선 그래프와 통행 규칙
- C++ 정적 충돌 데이터
- Unreal 배치·표현 데이터 참조
- 신호등, 횡단보도, 보행 경로
- 버전, 원본 출처, 생성 도구 버전, 체크섬을 담은 manifest

대용량 원본 에셋을 추가하기 전에 라이선스와 Git LFS/외부 저장 정책을 먼저 결정한다.
