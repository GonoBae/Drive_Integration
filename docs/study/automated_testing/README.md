# 자동 테스트 기술 교재

프로젝트에서 사용하는 자동 테스트를 실제 코드와 그림으로 설명합니다. 검사 방법뿐 아니라 사용 목적, 필요한 이유, 얻는 효과와 확인하지 못하는 범위를 함께 다룹니다.

## 교재 열기

- [그림 중심 PPT · 36쪽](B:/Portfolio/Drive_Integration/docs/study/automated_testing/output/DriveIntegration_Automated_Testing_v1.pptx)
- [상세 기술 교재 · 코드·실행 명령·결과 해석](B:/Portfolio/Drive_Integration/docs/study/automated_testing/output/자동_테스트_상세_교재.md)

PPT로 전체 흐름을 먼저 살펴본 뒤 같은 번호의 상세 교재를 읽으면 됩니다. PPT의 발표자 노트에도 자세한 설명을 넣었습니다. 모든 페이지에 그림이 있으며, 18개 페이지에는 실제 프로젝트 코드 발췌가 있습니다.

## 읽는 순서

1. **1–7쪽: 학습 기초.** 자동 테스트, 회귀 방지, 준비·실행·판정, 경계값과 허용 오차, 빌드와 실행의 차이를 익힙니다.
2. **8–15쪽: C++ 서버.** CTest, 통제된 시간, 프로토콜, 물리·접지·충돌·NPC·재생 검사를 살펴봅니다.
3. **16–23쪽: Unreal.** Automation 등록, 테스트용 월드, 좌표, 트럭 충돌 범위, 표시 재생, 깜빡이, 소리, 카메라·HUD 검사를 살펴봅니다.
4. **24–36쪽: 통합 검사와 활용.** 개발 도구, Protobuf, 실제 서버 통신, 프로세스 격리, 저장 맵, 패키지, 통합 실행기, 보고서와 성능 측정을 연결합니다.
5. **상세 교재 부록.** Windows 실행 명령, 실패 로그를 읽는 법, 용어, 설계 연습, 전체 검사 등록 목록과 과거 실행 근거를 확인합니다.

## 자료의 기준

2026년 9월 8일의 프로젝트 소스와 저장된 실행 기록을 기준으로 작성했습니다. 이번 교재 작성 중에는 게임 테스트를 새로 실행하지 않았습니다. 현재 코드에 등록된 검사 수와 과거 실행에서 통과한 수를 구분했으며, 자동 통과를 실제 주행·소리·화면 품질까지 보장하는 결과로 설명하지 않았습니다.

원리 그림은 설명을 위한 자료입니다. 실제 오류 화면은 별도로 표시했습니다. 그림의 출처와 제작 정보는 [그림 목록](B:/Portfolio/Drive_Integration/docs/study/automated_testing/ILLUSTRATIONS.md)에 정리했습니다.
