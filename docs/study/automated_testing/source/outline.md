# 자동 테스트 교재 편집 기준

대상은 Drive Integration을 공부하는 Unreal 클라이언트 지원자입니다. 기존 교재의 그림 중심 구성을 이어가되 테스트 자체의 기술, 목적, 사용 시점, 장점, 실제 검증 과정, 한계를 설명합니다.

주제별 데이터: id, section, title, question, imageKey, why, reading(두 문장), answer(약120–180자), followup, codeRef(선택: path/start/end/explain), sources(경로/행 또는 URL), notes(상세 설명 약500–900자).

notes에는 개념과 사용 기술, 준비/실행/판정, 왜 이 검사인지, 기대 효과, 한계가 있어야 합니다. 모든 슬라이드의 원문 설명과 코드는 별도 Markdown 교재에도 실어 발표자 노트를 열지 않아도 공부할 수 있게 합니다. 실제 소스 발췌는 빌드 때 다시 읽습니다. 도식은 실측 결과로 제시하지 않습니다.

구성: 학습 기초 A01–A07, C++ 서버 C01–C08, Unreal U01–U08, 통합 도구와 실행 W01–W13. 36쪽을 목표로 하며 파일 제목에 임의의 완료율을 쓰지 않습니다.

기존 파일과 게임 코드는 수정하지 않습니다. 이번 작업에서 게임 빌드·테스트·서버 실행을 하지 않습니다. 현재 소스의 테스트 등록 수와 과거 실제 실행 결과를 명확히 구분합니다.
