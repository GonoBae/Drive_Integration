# 코드 분석 학습 센터

학습 문서는 아래 **세 영역만** 사용한다. 별도의 날짜별 기록 파일은 만들지 않는다.

| 순서 | 문서 | 여기서 확인할 것 |
|---:|---|---|
| 1 | [일정](./schedule.md) | 오늘 할 학습, 현재 진도, 다음 복습일 |
| 2 | [학습자료](./lessons/README.md) | 단계별 설명, 읽을 코드, Quiz와 통과 기준 |
| 3 | [질문 및 답변](./qa.md) | 개념 답변과 접어 둔 Quiz 정답·해설 |

## 가장 간단한 사용 순서

1. 오전 10시 알림을 받으면 [일정](./schedule.md)의 `한눈에 보기`를 연다.
2. 링크된 [학습자료](./lessons/README.md)에서 오늘 범위만 공부한다.
3. 질문한 내용은 [질문 및 답변](./qa.md)에서 다시 찾는다.

현재 단계와 완료 여부는 [일정](./schedule.md) 한 곳에서만 관리한다.
