Protobuf 수업의 구성 예

객체를 바이트로 바꾸는 이유부터 시작합니다. .proto의 역할, protoc, 필드 번호와 타입, varint, 길이로 구분하는 데이터 형식을 읽은 뒤 실제 ControlCommand와 바퀴 목록으로 연결합니다.

예를 들어 정수 150을 바이트 96 01로 쓰는 계산을 직접 풀고, repeated WheelState wheels = 21에서 21과 wheel_index가 각각 무엇을 뜻하는지 설명합니다. 그다음 생성된 서버 클래스와 Unreal 자체 파서를 비교하고, 메시지를 해석했어도 서버가 입력을 거부할 수 있는 이유를 배웁니다.
