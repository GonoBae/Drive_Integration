## 단원을 읽는 방법

장 첫 페이지에서 학습 목적, 선수학습, 목표와 완료 기준을 확인합니다. 단원은 문제 상황과 사용 이유를 먼저 설명하고 개념·구체 예시·실제 소스코드·줄별 풀이·값 추적·확인 문제와 답으로 이어집니다. 끝에서는 다음 단원에 이 내용이 왜 필요한지 연결합니다.

**핵심 해설은 PPT 본문에 있습니다.** 노트에만 두지 않았습니다. 그림 옆에 한국어로 세 단계의 읽기 순서를 적었습니다. 먼저 그림으로 구조를 파악한 다음, 이어지는 설명과 코드에서 값을 따라가세요. [단원별 그림 목차](./illustrated/VISUAL_INDEX.html)에서 원하는 그림을 바로 찾을 수 있습니다.

- [1권 본문과 예제](./illustrated/01_Foundations_Protobuf_Textbook_illustrated2.html)
- [2권 본문과 예제](./illustrated/02_CPP_Server_Textbook_illustrated1.html)
- [3권 본문과 예제](./illustrated/03_Unreal_Client_Textbook_illustrated2.html)

PPT와 HTML 안에 그림과 코드 발췌를 넣었습니다. 인터넷·AI 연결 없이 읽을 수 있습니다. 공식 문서 링크는 추가 확인용입니다. 실제 코드 전체를 더 읽고 싶을 때만 프로젝트 폴더가 필요합니다.

## 학습 순서

처음에는 1권의 개념을 읽고 3권의 입력·표시 경로를 확인한 뒤, 2권에서 서버 계산을 이어서 읽는 순서를 권합니다. 모든 장을 한 번에 외우려 하지 않아도 됩니다.

첫날의 09:00~18:00 과정은 [교재 안내](./illustrated/START_HERE.html)에 따로 표시했습니다. 전체 601쪽을 하루 완료 목표로 잡지 않았습니다. 문제는 먼저 풀고 뒤의 풀이와 대조하세요.

ControlLease는 1권 L12의 160~179쪽, Unreal의 수신 공백·신선도·예측 한도는 3권 L08의 94~109쪽에서 확인할 수 있습니다. 처음 정독할 때는 해당 단원에 적힌 선수학습부터 진행하세요.

[이전 210개 학습 항목과 새 단원의 대응표](./illustrated/TOPIC_MAP.html)로 원하는 주제를 찾을 수 있습니다. 기존 설명·코드·확인 문제는 유지하고, 그림이 없던 24개 단원에 그림 페이지를 추가했습니다. 이전 교재는 `output`과 `revised` 폴더에 보관했습니다.

## 자료의 기준

- 실제 코드 발췌에는 경로와 작성 당시 줄 번호가 있습니다. 이후 코드가 바뀌면 함수 이름으로 다시 찾으세요.
- 교육용 숫자 계산과 실제 장애 재현 관측값을 구분했습니다.
- 자체 물리, NPC 판단, 센서, 모델·소리의 현재 한계도 설명합니다.
- 학습 자료 생성은 기존 정규 학습 진도의 완료를 뜻하지 않습니다.
- 그림은 내장 이미지 생성 도구로 만들었습니다. 저장소의 `assets`에 원본을 보관하며, [그림 설명과 프롬프트](./illustrated/ILLUSTRATIONS.md)를 함께 제공합니다.

프로젝트 코드와 서버를 변경하는 실습은 필수 과정에 넣지 않았습니다. 실행이 어려운 날에는 손계산과 코드·테스트 읽기로 진행할 수 있습니다.
