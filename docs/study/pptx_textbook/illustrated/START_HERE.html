  2. L07 연결된 서버가 같은 맵과 Play인지 확인하기
    Hello·지도 정체성·PlaySessionId·Sequence의 거절 이유를 설명합니다.

4장 늦게 온 상태로 화면 그리기

프레임·수신·시뮬레이션 시간을 배운 뒤 제한된 예측과 좌표 변환을 적용합니다.

  1. L08 다음 상태가 잠깐 오지 않으면 화면은 어떻게 움직이나요?
    세 시계와 표시 제한을 먼저 계산하고 서버 입력 타임아웃을 별도 방향으로 이해합니다.
  2. L09 서버의 위치를 Unreal의 차체 위치로 바꾸기
    ENU·FLU·Unreal 공간과 Heading·Pitch·Roll을 구분해 위치를 계산합니다.

5장 도로와 차량 구조를 표현하기

서버 계산 결과와 Unreal의 지면 측정·차체·운전자·휠 표시 사이의 책임을 연결합니다.

  1. L10 보이는 도로와 계산하는 지면을 맞추기
    지면 내보내기와 맵 정체성을 연결하고 NPC·차종·손상의 표현 책임을 설명합니다.
  2. L11 바퀴의 위치·조향·굴림을 따로 계산하기
    접촉점으로 허브를 복원하고 v/r와 프레임 시간으로 회전량을 계산합니다.

운전 시야를 확보하고 차량 상태를 카메라·계기판·소리·램프로 전달합니다.

  1. L12 시야를 가리지 않는 HUD와 돌아보는 카메라
    작은 화면의 배치 수치를 계산하고 마우스 이동량과 스틱 회전 속도를 구분합니다.
  2. L13 소리와 램프의 시작·유지·종료를 정하기
    RPM·스키드·경적·깜빡이·배기의 발동 조건을 수치와 상태 변화로 설명합니다.
