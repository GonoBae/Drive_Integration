# 충돌과 파손

서버가 접촉·충격·손상을 계산하고 Unreal은 메시 변형·캐릭터·파편을 표시합니다.
기능 구현과 실제 화면의 자연스러움은 별도로 확인합니다.

| 대상 | 현재 동작 | 구현하지 않은 범위 |
|---|---|---|
| 차량 | 차체 접촉·반작용, 위치/방향별 국부 정점 변형 | 금속 파괴·유리 파쇄·서버 충돌 외곽의 동일한 변형 |
| 보행자 | 강도별 밀림·전도, 몸통 이동·중력·접지, Unreal 팔다리 부분 래그돌 | 서버 전신 관절 충돌·실제 상해 판정 |
| 건물 | 접촉 부위 손상 흔적·파편 | 건물 전체 붕괴·벽 구멍 통과 |
| 신호등 | 기둥 전도·해당 신호 소등·기울어진 충돌 외곽 | 실제 강재 좌굴·부품 분리·자동 수리 |

차량 손상은 접촉점 주변의 작은 영역별로 보존합니다. 메시 원본은 유지하고 새 Play에서
복원합니다. 보행자는 넘어진 몸통의 낮아진 충돌 외곽을 사용하며 골반은 서버를 따르고
팔다리는 Unreal에서 표현합니다. 일어서기·걷기 전환의 자연스러움은 Play 확인 대상입니다.

## 사고 상태와 신호

신호등 하나가 쓰러졌다고 교차로 시간이 멈추지는 않습니다. 정상 head는 기존 주기를
유지합니다. 해당 차량 신호 그룹이 모두 고장 나면 NPC는 정지하며 고장을 녹색으로
간주하지 않습니다. 이미 진입한 주체의 이탈 규칙은 별도로 유지합니다.

같은 Play 재연결은 손상을 유지합니다. 새 Play/reset과 지도·traffic 교체는 초기화합니다.
파편은 표시용이며 서버 차량에 힘을 주지 않습니다. 사고 우회는
[NPC 주행](npc_navigation.md)의 공간·중앙선·후방 안전 조건을 따릅니다.

## 화면에서 확인할 것

1. F3로 차체·보행자 충돌 범위와 지면 접지를 확인합니다.
2. 차량 정면·측면·모서리에 각각 충돌하고 접촉 부위만 변형되는지 비교합니다.
3. 사람의 약한 접촉과 강한 충격을 비교합니다. 차량에 붙어 있거나 공중에 남으면 실패입니다.
4. 벽 충돌 위치에 따라 흔적·파편 위치가 바뀌고 벽 충돌은 유지되는지 확인합니다.
5. 신호등 하나를 쓰러뜨린 뒤 정상 신호 주기와 기둥 충돌 위치를 확인합니다.
6. 같은 Play 재연결과 새 Play에서 손상 유지/초기화를 각각 확인합니다.

[실행 안내](../guides/signal_city_quickstart.md), [검증 상태](../status.md)를 함께 봅니다.
수정 과정은 [이전 자료](../README.md#이전-자료)에 보관합니다.
