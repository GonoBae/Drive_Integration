# 구조물 충돌 피해

2026-09-03 사용자 승인 범위: 건물의 부분 외벽 피해와 신호등 기둥 전도·고장.
외부 물리 SDK를 도입하지 않으며, 건물 전체 붕괴는 포함하지 않는다.

## 현재 동작

- 건물: MapPackage의 `Wall` OBB에 차량이 충돌하면 충격량에 따라 피해가 누적된다.
  차량 OBB의 정면/측면/모서리 접촉 폭과 충격 강도에 따라 UE의 국부 균열·표면 손상 범위가
  달라진다. 다른 위치의 충돌 자국은 원래 위치에 남으며 피해 100% 이후에도 새 효과가 발생한다. 기존 건물 벽은
  그대로 충돌하므로 차가 파손된 외벽을 통과할 수는 없다.
- 신호등: 검증된 traffic head마다 `signal-pole-<id>` 충돌체를 만든다. 강한 충격으로
  기둥이 쓰러지고 해당 신호만 소등된다. 정상 신호는 같은 교차로라도 기존 신호 주기와
  잔여시간을 유지한다. 같은 차량 신호 그룹에 정상 신호가 남아 있으면 NPC는 그 신호를
  따르며, 해당 그룹이 전부 고장 나면 정지한다. 고장 난 신호는 통행 허가로 사용하지 않는다.
  이미 교차로/횡단보도에 진입한 주체의 기존 이탈·통과 규칙은 유지한다.
- 쓰러진 기둥: 전도 각도에 맞춘 보수적 상자 외곽을 서버 충돌에 사용한다.
  원래 높이의 직립 충돌체를 남기지 않는다. 자동으로 일어서거나 수리되지 않는다.
- 같은 Play의 재연결은 피해를 유지한다. 새 Play/reset, 지도·traffic 교체는 초기화한다.
  SafeStop 중에는 전도 계산을 정지한다.

## 계산·표시 경계

`StructureDamageRuntime`이 충돌 접촉의 normal impulse를 받아 250ms 접촉 구간의 최대값으로
피해를 계산한다. 약한 지속 압력을 매 tick 중복 누적하지 않는다. 별도 충돌 구간은 추가
피해가 될 수 있다. 건물 손상 시작 900N·s, 기둥 손상 시작 250N·s·전도 기준 2,500N·s는
데모 튜닝 값이며 실제 재료의 파괴 한계 측정값이 아니다.

기둥은 높이 3.85m·180kg 균일 봉의 지지점 관성, 충격량, 중력과 감쇠를 이용한 힌지 모델이다.
차량 접촉에서는 고정 지지부의 저항을 넘긴 뒤 180kg 충돌체로 밀려난다. 완전한 자유 강체·
실제 강재 좌굴이나 부품 분리를 계산하지 않는다. 쓰러진 상태의 충돌 외곽은 시각 메시보다
보수적일 수 있다. 건물도 실제 지오메트리를 절단하거나 벽의 구멍을 만드는 기능은 아니다.

tick 시작에 이전 접촉 결과로 피해·전도를 갱신한 후, 같은 기둥 pose를 차량 물리와
WorldState에 사용한다. 기둥 proxy는 기존 Ego 물리 기록의 외부 충돌 입력에도 포함된다.
정적 MapPackage 파일과 checksum은 수정하지 않는다.

`WorldState.structures`와 `TrafficSignalState.out_of_service`를 additive 필드로 전달한다.
피해 이벤트·ID·유한 좌표·법선·전도 각도·신호 고장/기둥 피해 일치 여부를 검증한 snapshot만
원자적으로 적용한다. 건물 접촉점은 실제 외벽 OBB 표면으로 투영해 표시가 벽 안에 묻히지
않도록 한다. UE는 서버 pose·피해를 표시하고 자체 충돌 판정을 서버에 되먹이지 않는다.

UE 표시 예산은 피해 건물 최대 32개, 건물당 최근 손상 흔적 8개(흔적당 균열/표면 조각 24개)
및 파편 최대 24개다. 파편은 6~15cm 크기로 외측·상향 분사하며 3.2초 후 사라진다.
WorldStatic ray query와 바닥 높이 fallback으로 튕김만 표시하고, 차량/서버에 힘을 가하지 않는다.
같은 이벤트를 반복 수신해도 다시 생성하지 않는다. 기둥과 피해 표시 자체는 Chaos 물리를 쓰지 않는다.

## Play 확인

1. 수정된 UE 모듈과 Signal City 서버로 기존 `/Game/SignalCity/Maps/L_SignalCity` 맵을 Play한다.
   이번 변경 때문에 지도 생성이나 Ground Bake를 다시 할 필요는 없다.
2. 건물 외벽에 충돌해 접촉 부위의 균열·파편, 벽 충돌 유지 여부를 확인한다.
3. 신호등 기둥에 충분한 속도로 충돌해 전도·소등, 같은 교차로의 정상 신호가 계속 바뀌는지 확인한다.
   기둥이 쓰러진 위치에도 장애물이 남는지 확인한다.
4. Stop 후 다시 Play하여 피해·기둥 자세·신호가 초기화되는지 확인한다.

자동 검증과 실제 화면/조작감 인수는 구분한다. 최신 결과는
[9월 3일 작업일지](./worklogs/2026-09-03.md#후속-요청-구조물-충돌-피해)에 기록한다.

9월 7일 후속 수정에서는 신호등 하나의 파손이 제어기 전체를 영구 적색으로 만들던 동작을
신호 개별 고장으로 분리했다. 파손 후 300초간 정상 신호의 주기·잔여시간 유지와,
서버·UE 양쪽에서 정상 신호 간 상충 통행 허가를 계속 거부하는 회귀검사를 추가했다.
이 검사는 직접 주행한 화면 검증을 대신하지 않는다.
