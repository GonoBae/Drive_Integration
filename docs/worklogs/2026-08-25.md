# 2026-08-25 작업 로그

## 목표

8월 20일에 실행하지 못한 AI-D7의 남은 범위를 보충해 WP-01 좌표 계약과 WP-02
차량 기반의 자동 게이트를 닫는다. 차량 수치를 코드에서 분리하고, 시험용 평면이 아닌
MapPackage 지면에서 차체 높이와 자세가 경사를 따라가도록 만든다.

## 구현

- `cpp/host/config/vehicle_sedan.cfg`에 R1 generic sedan의 차량·타이어·구동·제동·
  서스펜션 SI 파라미터 전체를 이동했다.
- `vehicle_config` loader는 format version, 전체 key 존재 여부, unknown·duplicate,
  finite 수치와 물리 범위를 검사한다. 실패 시 기본값으로 조용히 대체하지 않고 서버
  시작을 중단한다.
- 설정 파일 bytes의 FNV-1a 64 checksum을 시작 로그에 기록하고 `--vehicle-config`로
  재컴파일 없이 다른 설정을 선택할 수 있게 했다.
- `MapPackageGroundQuery`가 `ground_surface.csv`의 ENU triangle을 읽고 vertical ray가
  포함되는 표면 중 가장 가까운 높이와 정규화된 up-facing normal을 반환한다.
- Wall/Broad v1에는 WP-03 전까지 사용할 넓은 평면 bootstrap triangle 2개를 추가했다.
- `VehiclePhysics`가 suspension normal load로 vertical speed와 `position_enu.z`를
  적분하고, 평균 노면 normal을 body forward/left slope로 변환해 pitch·roll 목표와
  경사 중력 성분을 계산한다.
- 공개 FLU roll은 X축 right-hand rule을 따르고 Unreal FRU 변환은 기존 경계의 한 번의
  negation만 사용하도록 roll angle·angular velocity 부호를 일치시켰다.
- `SimulationHostConfig`에 외부 `VehicleParameters`와 `GroundQuery`를 주입하고 서버는
  `--map-package`로 지면 package를 선택한다.
- Unreal `GroundCollisionExporter` actor가 지정된 시험 구간의 실제 `WorldStatic`
  충돌을 수직 raycast로 샘플링해 ENU triangle CSV로 원자적으로 교체한다. 선택적
  `Ground Actor` 필터, 누락 cell·과도한 높이 단차 제외, 20,000 triangle 상한과
  저장소 `map_packages/` 경로 제한을 적용했다.
- 이 기능은 Unreal hit를 주행 중 서버로 되먹이지 않는다. bake snapshot을 서버 재시작
  시 로드해 C++ 단독 물리 권한·60Hz 지연 예산·결정성을 유지한다.

- `PHY-010` 차량 파라미터 파일화는 구현 상태로 전환한다.

  force와 정적·동적 충돌은 후속이므로 구현 중을 유지한다.
- `PHY-011`은 실제 경사 주행까지 자동화했지만 충돌·replay가 남아 구현 중을 유지한다.

  PIE에서 시각 확인한 뒤 M2 최종 완료로 선언한다.
