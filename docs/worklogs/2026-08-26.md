# 2026-08-26 작업 로그

## 목표

Unreal Editor에서 만든 Landscape 지면과 명시적 정적 OBB collider를 C++ SimCore의
권한 충돌 snapshot으로 연결하고, 같은 `WorldState`에서 동적 demo entity까지 검증할
수 있는 WP-03 자동 경로를 만든다.

## 구현

- `GroundCollisionExporter` editor-only actor를 추가했다.
- 지정된 sampling box의 `WorldStatic` 충돌을 위에서 아래로 raycast한다.
- 다른 Floor나 overhead collider가 겹칠 때는 `Ground Actor`로 Landscape 하나를
  명시해 hit를 제한할 수 있다.
- 네 모서리 hit가 모두 존재하는 cell만 삼각형 2개로 만든다. 여러 `WorldStatic`을
  무필터로 스캔할 때는 `Max Cell Height Delta`를 넘는 cell을 연결하지 않으며, 명시한
  `Ground Actor`는 하나의 연속 authored surface로 취급해 급경사 cell을 유지한다.
- Unreal world cm를 `east=Y/100`, `north=X/100`, `up=Z/100` ENU meter로 변환한다.
- 출력은 저장소의 `map_packages/` 아래로 제한한다. ground와 static CSV를 각각 임시
  파일에 완성해 교체하고 실제 bytes checksum의 `manifest.cfg`를 마지막에 commit한다.
- 한 번에 최대 20,000 triangle만 허용한다. 기본 60m×30m, 1m sampling 영역은 약
  3,600 triangle이다. 이후 C++ 지면 질의에는 adaptive grid와 한정 fallback을 추가했다.
- runtime UE hit를 서버로 되먹이는 프로토콜은 추가하지 않았다. bake snapshot을 서버
  재시작 시 로드해 C++ 단독 권한·결정성·저지연 경로를 유지한다.

## 수동 검증 절차

1. `NewMap`을 열고 `SimCore Ground Collision Exporter`를 배치한다.
2. `Ground Actor`에 만든 Landscape를 지정한다.
3. sampling box가 평평한 spawn과 요철 주행 구간을 덮도록 위치·extent를 조정한다.
4. 벽·커브 시험이 필요하면 `SimCore Static Collider` marker를 배치하고 고유 ID,
   semantic, box 크기·Yaw를 설정한다.
5. `Bake Ground + Static Collision To MapPackage`를 누른다.
6. 서버를 `--map-package .\map_packages\landscape_local_v1`로 재시작한다. 동적 fixture도
   볼 때는 `--demo-entities`를 함께 지정한다.
7. PIE에서 네 바퀴 접지, z·pitch·roll, 정적 벽 비관통, NPC·보행자 identity/표시/충돌,
   60Hz tick overrun을 확인한다.

### PIE 재실행 자동 SimulationReset

- schema v2 `Envelope`에 additive payload `SimulationReset`을 추가했다. 새 payload는
  `play_session_id`와 `client_time_ns`를 가지며 map checksum, source, connection session,
  sequence는 공통 Envelope metadata를 사용한다.
- Unreal은 `BeginPlay`마다 새 play session ID를 한 번 만들고 WebSocket 연결 직후
  `SimulationReset`을 첫 `ControlCommand`보다 먼저 보낸다. 서버는 새 play session을
  받으면 차량을 configured spawn으로 되돌리고 simulation clock·control lease·입력
  상태를 초기화한 뒤 현재 `WorldState`를 즉시 발행한다.
- transport가 같은 PIE 안에서 재연결되면 connection session만 새 GUID로 바뀌고 play
  session ID는 유지된다. Unreal은 reset을 재전송하지만 서버는 `(source_id,
  play_session_id)`로 중복을 식별해 pose와 clock을 다시 초기화하지 않는다. SafeStop을
  거쳐 새 connection으로 control lease만 넘긴다.
- 새 PIE reset과 같은 PIE reconnect 모두 이전 socket session을 retired 상태로 남긴다.
  따라서 연결 종료 전에 큐에 있던 command나 이전 PIE에서 늦게 도착한 command는 새
  주행을 다시 움직일 수 없다.
- 서버는 WebSocket accept마다 단조 증가 connection generation을 발급한다. 현재 owner보다
  낮은 generation의 reset/control과 새 socket의 session ID 재사용을 mutation 전에 거부한다.
  reset 후보가 retired session이면 기존 lease를 먼저 파괴하지 않는 원자적
  validate-then-commit 경로를 사용한다. 단, 유효한 E-stop은 안전 우선순위상 lifecycle
  owner와 무관하게 latch되며 일반 주행 control에만 generation fence를 적용한다.
- `WorldState` Envelope가 현재 play session ID를 echo하고 Unreal은 로컬 PIE ID와 다른
  state를 표시 전에 폐기한다. 새 PIE handshake 직후 서버가 보낸 pre-reset 이전 위치가
  화면에 잠깐 적용되지 않는다. reset 즉시 snapshot에도 현재 Unix timestamp를 넣는다.
- process-lifetime E-stop latch는 안전 경계를 유지한다. E-stop 중 `SimulationReset`은
  거부되며 control도 계속 차단된다. E-stop 해제에는 서버 프로세스 재시작이 필요하다.

### 접지는 유지하지만 RWD가 경사를 오르지 못한 원인과 수정

- 후속 상태 확인에서 네 바퀴의 geometry contact는 유지됐지만 앞바퀴에만 하중이
  몰리고 구동축인 뒤 차축의 published normal load가 0이 됐다. 기존 코드는 개별
  suspension spring force를 그대로 타이어 법선 하중으로 사용했으므로 뒤 spring이
  full droop이면 마찰 한계 `mu*N`도 0이 됐다. throttle 토크가 RWD에 전달돼도 노면
  추진력이 생기지 않은 직접 원인이다.
- 외부 차량 물리 SDK는 도입하지 않았다. `VehiclePhysics`에 quasi-static double-track
  force/moment equilibrium을 적용해 합성 경사의 총 법선 하중을 `m*g*n_up`으로 두고,
  CG 높이와 종·횡 접촉력으로 앞뒤 및 좌우 하중 이동을 계산한다.
- 차량 설정을 format v2로 변경해 `front_static_load_fraction`,
  `front_drive_torque_fraction`, `front_service_brake_fraction`을 추가했다. 기본 sedan은
  `0.55/0.0/0.65`이며 `front_drive_torque_fraction=0.0`은 기존 RWD 구성을 유지한다.
  정적 앞축 하중 비율로 CG부터 앞·뒤 차축까지의 실제 모멘트 암도 함께 계산한다.
- 조향은 Ackermann 기하로 각 앞바퀴 각도를 계산한다. open differential는 같은 차축의
  양쪽에 같은 토크를 주되 각속도를 독립 적분하므로 직진에서는 좌우가 대칭이고
  선회에서는 안쪽·바깥쪽 회전수가 달라진다.
- 60Hz fixed tick에서 stiff longitudinal tire를 explicit Euler로 적분해 마찰 한계를
  번갈아 넘던 진동은 바퀴 각속도와 종방향 타이어 힘의 implicit coupling으로
  안정화했다.
- 노면 normal에서 orthonormal longitudinal/right tangent basis를 만들고 중력 성분과
  ENU 이동을 같은 basis로 계산해 compound pitch·roll 경사에서도 힘과 이동 방향을
  일치시켰다.
- 자동 회귀는 20° 평면의 총하중과 양 차축 하중, 기본 RWD 지속 등판, 직진 좌우
  회전수 대칭, 선회 차동 회전과 Ackermann 조향을 검증한다. Windows Release CTest는
  9/9를 통과했다.

이 결과는 generic sedan 자체 모델의 회귀 결과다. 특정 차종 계측 데이터에 대한 정밀
정합이나 현재 사용자의 Landscape에서의 최종 PIE 등판 확인을 완료했다는 의미는 아니다.

### MapPackage 실제 충돌 checksum과 시작 lifecycle gate

- 각 MapPackage에 strict `manifest.cfg`를 추가했다. 필수 필드는 `format_version`,
  `map_id`, `coordinate_frame`, `collision_files`, `collision_checksum`이며 unknown·duplicate·
  missing key, unsafe filename, payload 누락을 시작 실패 처리한다.
- checksum은 manifest 문자열을 신뢰하지 않고 `collision_files`에 나열된 파일명과 실제
  raw bytes를 정해진 순서로 FNV-1a 64 계산한다. 현재 `landscape_local_v1`과
  `wall_broad_v1`은 각자의 `ground_surface.csv` 실제 내용과 일치하는 값을 가진다.
- `GroundCollisionExporter`는 ground/static CSV를 임시 파일에 staging하고 각각 교체한
  뒤 실제 payload checksum의 `manifest.cfg`를 마지막에 commit한다. collision 저장 도중
  실패하거나 payload만 바뀐 상태는 다음 서버·Unreal 시작에서 fail-closed된다.
- C++ host는 package manifest와 payload를 검증한 checksum을 모든 `WorldState`에 싣는다.
  Unreal도 연결 전에 로컬 manifest와 payload를 독립 검증하고, 연결 후 처음 받은
  `WorldState` checksum이 로컬 값과 일치해야만 `SimulationReset`과 첫 일반
  `ControlCommand`를 전송한다.
- 서버는 checksum-valid `SimulationReset`으로 source/session/play lifecycle이 열리기
  전의 일반 control을 거부한다. 초기화되지 않은 client도 차량을 멈출 수 있도록 E-stop만
  reset 전 안전 예외로 유지한다.
- checksum 또는 schema identity가 불일치하면 Unreal은 incompatible 상태로 socket을
  닫고 자동 재연결을 중단한다. 이 경계는 명시적 Protobuf `Hello` capability 교환을
  대체하지 않으며 `Hello`는 후속이다.

### WP-03 정적·동적 CollisionWorld 자동 기반 선행

- manifest에 명시된 `static_colliders.csv`만 읽는 strict loader를 추가했다. 고정
  12-field header와 `collider_id`, `wall/curb/barrier` semantic, `obb` shape,
  `map_enu` center·heading·half extent, friction·restitution을 검증한다. 중복 ID,
  undeclared/변조 payload, 잘못된 header·수치·크기·재질은 시작 실패한다.
- 차체와 정적 장애물의 수평 OBB 네 축 SAT에 수직 interval을 결합해 OBB-prism
  manifold를 계산한다. 초기 관통은 contact normal 방향으로 projection하고, normal
  impulse와 restitution, Coulomb friction 제한 tangent impulse로 ENU 선속도와 yaw rate를
  함께 해결한다.
- tick 이동량 0.10m, 회전량 1°를 넘지 않게 microstep으로 나누며 상한은 64다. 필요한
  step이 상한을 넘으면 unchecked 운동을 계속 적분하지 않고 허용 구간까지만 clamp한다.
  collider/proxy ID 정렬과 고정 solver iteration으로 입력 순서 결정성을 유지한다.
- `VehiclePhysics`가 타이어·중력으로 예측한 ENU 수평 속도를 `CollisionWorld`에 전달하고
  해결된 east/north·heading·yaw rate를 authoritative 차량 상태로 다시 가져온다. 지면
  높이 Z와 pitch/roll·휠 접지는 기존 `GroundQuery` 경로가 분리해 계속 소유한다.
- 충돌로 heading이 바뀌어도 작성된 ENU 지면 normal은 회전시키지 않는다. 차체 수직
  interval은 step 시작·예측 끝의 지면 높이를 모두 포함해 보수적으로 sweep하고, 해결된
  XY 변위는 같은 고정 normal에 한 번만 투영해 Z를 갱신한다. 이로써 경사 벽 접촉에서
  지면 평면이 함께 회전하거나 높이 변화가 이중 합산되는 경로를 제거했다.
- NPC 차량용 kinematic OBB와 보행자용 vertical capsule 최소 API를 추가했다. proxy는
  선·각속도로 microstep마다 진행하고 contact point의 상대속도가 Ego impulse에 반영된다.
  무한질량 kinematic proxy 자체 상태는 solver가 변경하지 않는다.

### WP-03 자동 구현 마감 후속

- `MapPackageGroundQuery`에 adaptive grid index를 추가했다. 정상 grid는 수직 ray 후보를
  줄이고, 겹침이 과도한 입력만 한정된 global fallback을 사용한다. indexed/brute-force
  hit 일치, 경계 보존, 후보 감소 회귀를 추가했다.
- `CollisionWorld`는 8m uniform grid에서 정적·동적 후보를 수집하고 ID 순으로 정렬·중복
  제거한다. cell 예산을 넘는 큰 collider만 안전 fallback으로 보존하며 brute-force와
  동일한 해결 결과를 시험한다.
- editor-only `ASimCoreStaticCollider` Box marker를 추가했다. 사용자는 고유 ASCII ID,
  wall/curb/barrier semantic, friction/restitution과 export 여부를 명시하며 exporter가 이를
  자동 수집해 strict 12-field `static_colliders.csv` OBB로 변환한다. marker가 없으면 이전
  장애물을 남기지 않고 header-only 파일을 쓴다.
- host의 opt-in `--demo-entities` 경로는 ground가 존재하는 위치에 NPC OBB 1대와 보행자
  capsule 1명을 만들고 move/reset lifecycle과 Ego collision snapshot을 관리한다. protocol은
  identity·kind·shape·pose·velocity를 `WorldState`로 발행하며 Unreal은 transient mesh proxy를
  생성·갱신·제거한다.
- 위 항목으로 **WP-03 자동 구현은 완료**했다.
- 실제 `landscape_local_v1`에는 아직 marker를 배치·bake하지 않아
  `static_colliders.csv`가 header-only이고 로드 수는 `static_colliders=0`이다. 실제 PIE
  벽·커브 및 demo entity identity/표시/충돌은 실행하지 않았으므로 WP-03 전체와
  PHY-006·PHY-007·AT-03·AT-04는 계속 **진행 중**이다.
