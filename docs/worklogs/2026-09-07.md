# 2026-09-07 작업 현황과 일정 점검

지금까지 구현한 내용과 검증 기록을 정리했습니다. 오늘은 문서와 Git 반영이 작업 범위이며,
차량 코드·맵을 추가로 수정하거나 빌드·시험을 새로 실행하지 않았습니다.

## 현재까지 구현한 내용

| 구분 | 현재 상태 |
|---|---|
| 서버·클라이언트 | Unreal Engine 5.6과 C++ 60Hz 서버를 WebSocket/Protobuf로 연결합니다. Play 초기화, 재연결, Hello 호환성 검사와 MapPackage 자동 재로딩을 처리합니다. |
| 지면·차량 물리 | Unreal이 지면·정적 충돌을 측정하고 서버가 접지·타이어·서스펜션·차체 자세를 계산합니다. 전진·후진, 조향·제동·사이드 브레이크, 경사·연석·차체 충돌을 구현했습니다. |
| 플레이어 차종 | `1` 세단, `2` 경차, `3` 트럭, `4` 오토바이를 선택합니다. 차종 변경은 새 주행으로 초기화하며 서버 물리 설정과 화면 외형을 함께 바꿉니다. |
| 도심·신호 | `L_SignalCity`에 교차로 2개, 방향성 차로 58개, 신호 head 16개, NPC 10대와 보행자 8명이 있습니다. 네 collector 커브의 차선 교차를 수정해 저장 맵에도 반영했습니다. |
| NPC 판단 | 목적지 선택, 경로 우회, 같은 방향 차선 변경을 구현했습니다. 장애물이 너무 가까우면 후방이 안전할 때 최대 6m를 저속 후진해 회피 공간을 만듭니다. |
| 충돌·사고 | 차량의 반복 충돌과 사고 상태, 저속 운전 복귀, 충돌 위치별 메시 찌그러짐, 구조물 부분 손상·파편·전도, 보행자 밀림·낙상·회복을 구현했습니다. |
| 표시·조작 | HUD, 카메라 회전·줌, 방향지시등·비상등, 클락션, 엔진·마찰음과 배기가스를 추가했습니다. 세단 실내·운전자, 문 개폐·하차·항의·복귀도 표시합니다. |
| 기록·확인 도구 | F3 충돌·접지 표시, F5 주행 기록/F6 시각 재생, 별도 서버 입력 기반 물리 재생과 성능 측정 도구를 구현했습니다. 차종을 기록·재생하고 새 세션에서 센서 metadata도 초기화합니다. |

물리와 표현의 범위는 구분합니다. 차량은 자체 4접점 축약 모델이며 오토바이의 실제 이륜 균형은
구현하지 않았습니다. NPC는 도로 그래프와 주변 상태를 이용하는 규칙 기반 판단이고, 자유 공간의
자율주행은 아닙니다. 보행자의 이동 경로는 횡단보도 중심입니다. 차체 dent는 표시 메시 변형이며
금속 파괴나 변형된 차체 충돌체 계산은 아닙니다. 보행자 ragdoll에는 Unreal 표시용 엔진 물리를
사용하지만 차량 계산과 이동 상태의 권한은 서버에 유지합니다.

세단 외 플레이어 차체는 기능 검증용 모델입니다. 세단용 실내·운전자를 다른 차종에 그대로
표시하지 않습니다. 원경 지면과 스카이라인은 화면의 끊김을 가리는 비충돌 배경이며 실제 주행
영역을 넓힌 것은 아닙니다.

Editor/Game 빌드 성공도 배포용 패키지 성공을 뜻하지 않습니다.

## 일정과 남은 작업

| 기준 일정 | 9/7 점검 결과 |
|---|---|
| 9/4 조건부 Core 조기 인수 | 미달성. 실제 주행·패키지·성능 인수가 남았습니다. |
| 9/7 Core RC 목표 | 목표 당일이며 아직 인수 완료가 아닙니다. 추가 기능은 늘었지만 미완료 검증을 먼저 마쳐야 합니다. |
| 9/8 Core 수정 버퍼 | 위 인수에서 확인된 문제를 수정하는 기간입니다. 완료를 보장하는 날짜는 아닙니다. |
| 9/9~11 Should 확장, 9/14 위험 버퍼 | Core 인수를 먼저 통과해야 합니다. 지연되면 확장 범위나 일정도 다시 조정해야 합니다. |

주말 제외 일정은 유지합니다. 9/5 토요일에 실제 작업한 기록이 있다는 이유로 앞으로의 주말을
정규 작업일에 포함하지는 않았습니다. 날짜를 이번 정리에서 임의로 늦추거나 완료 처리하지 않았습니다.

우선순위는 다음과 같습니다.

1. 최신 코드 전체 통합 검증과 `L_SignalCity` 실제 주행: 네 차종, 커브 차선, 근접 후진·회피,
   충돌·찌그러짐·보행자·문 개폐, HUD·재연결, 기록·재생을 함께 확인합니다.
2. 남은 카메라 모드와 패키지 실행 설정·배포 시험을 마칩니다. 현재는 외부 추적·회전·줌
   카메라이며 운전석·고정·자유 카메라 전체가 완료된 것은 아닙니다.
3. 목표 PC에서 패키지 1920×1080/60fps, 입력 반응 지연, 30분 연속 주행을 측정합니다.
4. Core 인수 후 최종 아트·촬영·포트폴리오 설명과 합의된 Should 확장을 진행합니다.

SensorRig는 장착 위치·시간·프레임 metadata 단계입니다. 실제 RGB 영상은 Should,
LiDAR/radar/segmentation은 Future로 구분하며 Core 필수 미완료로 추가하지 않았습니다.
시각 재생에는 타임라인·탐색·배속 UI가 없고, 서버 재생도 전체 NPC AI가 아닌 Ego 물리 재현입니다.
