## 반영 범위

- NPC 근접 회피·짧은 후진·중앙선 침범 금지와 우회 도중 재차 차단됐을 때의 복구.

- 차량·보행자 표현, 접지·충돌·재생, 도로·신호와 지도 데이터의 누적 수정.
- 관련 자동 시험, 입력 반응 측정 절차와 Windows 배포 파일 식별·검사 도구.
- 하루 학습 안내, 서버·Unreal·Protobuf 교재, 면접 자료와 자동 테스트 교재.
- README·일정·기능표·기술 문서 및 9/8·9/9·9/17 작업 기록.

교재의 PPT·HTML·그림·ZIP은 학습 자료로 포함합니다. 실행 로그, 캐시, 빌드 산출물,
배포 실행 파일은 기존 Git 제외 규칙을 유지합니다. 로컬에만 있는 검사 자료의 링크는
원격에서도 열리는 링크로 오해하지 않도록 경로 표기로 정리했습니다.
