## 충돌 후 진행과 사고차 회피 후속

9/3의 충돌·교통 피드백 작업을 이어서 다음 네 항목을 수정했다.

1. 지면에 완전히 쓰러진 낮은 신호등/보행자만 타이어 지지 후보로 분류한다. 둥근 축약
   표면과 타이어의 접촉점·법선을 기존 네 바퀴/서스펜션 계산에 전달한다. 높은 물체,
   공중 물체, 지면이 없는 곳, 바퀴 사이에서 차체 하부보다 높은 물체는 계속 막는다.
2. 신호등은 무한 질량 장애물이 아니다. 남은 기초부 저항을 먼저 소진하고 같은 충돌
   microstep에서180kg 유한 질량 기둥과 잔여 충격을 교환한다. 방출된 위치·선속도·회전을
   다음 tick에도 유지하며, 벽은 기존 강체로 남긴다. 새 Play에서는 원래 배치로 복원한다.
3. 보행자는 수평 충격에 임의의 위쪽 발사를 더하지 않는다. 접촉 높이와 질량중심 사이의
   팔길이로 각충격량을 계산하고, 위에서 실제로 겹친 보닛/유리/지붕의 근사 표면에만
   지지한다. UE 팔다리 초기 속도는 `몸통 선속도 + 각속도 × 위치`를 사용한다.
4. 옆 차로가 빌 때까지 기다리며 사고차 바로 뒤로 접근해 변경 경로를 잃던 교착을
   재현했다.8m 조향 여유를 보존하고, 안전한 전체 변경 계획이 생길 때 예약 정지를
   해제한다. 대기 이유는 바뀔 때만 기록한다.

통합 중 보행자 대기점이 신호등 기둥과4cm 겹치는 실제 배치도 발견했다. 보행자 경로의
좌우 offset을0.45m에서0.60m로 늘렸다. 또한 충돌 회귀를 신호 진입 정책과 분리된 직접
NPC–보행자 유한 질량 접촉으로 바꿨고, 보행 헤딩은 첫 대기점 이탈 변위가 아니라 원본
횡단보도 방향과 비교한다. 제품 충돌 기준이나 보행 신호 조건을 느슨하게 하지 않았다.

## 운전자 하차·보행 충돌·NPC 복귀/회피·도로 표시 후속

사용자 PIE에서 확인된 여섯 항목만 범위로 잡아 다음과 같이 보완했다.

1. 세단 본체에서 좌측 앞문의 외판·유리·프레임·손잡이·미러를 분리해 실제 개구부와
   `SM_SedanDoorLeft`를 저작한다. 사고 뒤 운전자는 손을 실제 힌지에 붙은 손잡이로 먼저
   옮겨 문을 열고, 왼발과 오른발을 순서대로 문턱 밖으로 옮긴 뒤 차 밖에 선다. 양발은
   실제 `WorldStatic`의 충돌점 전체 좌표와 법선을 사용해 경사·연석 높이에 맞추고,
   골반 이동·무릎 굽힘·발바닥 방향을 함께 계산한다. 문을 손으로 닫은 뒤 한 손·손목·
   상체를 서로 다른 주기로 움직여 항의하며, 복구할 때는 반대 순서로 좌석에 돌아간다.
   분리된 문도 기존 contact-local dent patch와 reset을 차체와 동일하게 적용한다.
2. 보행자 충돌에는 임의의 위쪽 발사 속도를 더하지 않는다. 서버의 실제 접촉과
   9.81m/s² 중력으로 낙하하며 과도한 회전 속도는 제한한다.
3. 넘어진 보행자의 각 UE 래그돌 부위 아래에서 `WorldStatic`을 따로 조회한다. 실제
   충돌점·법선을 사용해 경사면 안쪽 속도만 제거하고 관통 보정 속도를 제한한다. 공중이면
   임의의 평면을 만들거나 즉시 붙이지 않고 중력 속도로 내려오므로 경사·연석에서도 몸
   일부가 뜨거나 평지 기준으로 박히는 현상을 줄였다.
4. 경미한 충돌 뒤 NPC는 세계 좌표로 옆으로 미끄러져 경로에 붙지 않는다. 운전자가
   역순으로 탑승하도록 `Recovering` 시작 뒤 2초간 현재 자세를 유지한다. 그 다음 충돌
   뒤의 차체 방향과 차선 방향을 시작·끝 접선으로 삼는 하나의 복귀 곡선을 만들고, 한 번
   정한 전진 또는 후진 방향으로 저속 주행해 합류한다. 후보점의 실제 tick 이동 거리,
   tangent, yaw 속도·가속도를 모두 검사하고 조건을 만족하지 못하면 움직이지 않고
   재계획한다.
5. 정차한 Ego가 앞길을 막으면 최대 80m 앞에서 장애를 판단한다. 안전한 저작 인접 차로가
   있고 기존 목적지에 닿을 수 없으면 막힌 원래 차로를 제외하고 도달 가능한 새 목적지를
   선택한다. 정상적인 경로 끝은 물리 장애물로 판단하지 않는다.
6. 생성된 직선·곡선 도로 구간 전체에 중앙선과 양쪽 가장자리 표시를 추가했다. 네 곳의
   collector 전환부에도 노란 중앙선 bevel과 양쪽 흰색 merge boundary를 이어 붙이고,
   다차로 접근로의 점선 차선 구분도 유지한다. 저장 맵은 기존 생성 상태를 정확히 확인하고
   백업한 뒤 소유한 표시 geometry만 갱신한다.

서버 Release 전체 **CTest 32/32**를 통과했다. 새 회귀는 40m 밖의 정차 Ego를 발견해

## 자연스러운 차선·근접 회피·차종/운전자 표현 후속

사용자가 요청한 열 가지 항목을 같은 날의 최신 상태로 반영했다. 이 절의 지도 identity와
실행 서버 정보가 위 절의 이전 실행 상태를 대체한다.

1. 두꺼운 상자처럼 보이던 노면 표시를 2mm 도색으로 낮췄다. 대각선으로 꺾이던 합류선은
   6개 구간의 곡선 테이퍼로 바꾸고, 중복 끝선과 과도하게 넓은 collector 도로를 정리했다.
2. 코스 밖에는 충돌하지 않는 원경 지면과 스카이라인 건물 18개를 추가했다. 실제 주행·충돌
   영역을 무한히 늘린 것이 아니라, 멀리 보았을 때 맵이 갑자기 끊겨 보이는 현상을 줄이는
   표시용 배경이다.
3. NPC가 앞차에 너무 가까워 최소 8m 차선 변경 곡선을 만들 수 없으면
   `WaitingForStop → Backing → ReadyToPass` 순서로 처리한다. 현재 차선 안에서 최대 6m,
   1.4m/s 이하로 후진하고 0.25m 간격 swept 검사와 후방 1m 여유를 통과한 경우에만 공간을
   만든다. 후방 차량·구조물이 있으면 후진하지 않으며, 장애물이 사라지면 취소한다.
4. NPC 판단은 0.25초마다 신호 통행권, 동적 장애물, 사고·폐쇄 차선, 인접 간격, 목적지
   도달 가능성을 다시 평가한다. 고정 경로 재생은 아니지만, 카메라·라이다 기반 자유공간
   자율주행이 아니라 저작된 lane graph 안의 상황 판단·로컬 재계획이다.
5. NPC ID 순서로 세단·경차·트럭·오토바이를 반복 배치한다. 차종마다 화면 메시와 바퀴 수,
   램프 위치뿐 아니라 OBB 크기, 질량, yaw 관성, 최고속도 비율, 가속·제동, 전도 크기를
   다르게 사용한다. 차선 변경 간격·지면 지지·정지 거리도 해당 차종 크기를 사용한다.
6. `X` 비상등과 `Q/E` 방향지시등 상태를 HUD에 표시하고 램프를 3600cd·450cm로 강화했다.
   운전자 골반을 낮춰 지붕 관통 여유를 만들고, 실제 핸들 좌표의 9시·3시 위치를 양손이
   잡도록 팔꿈치 힌트까지 조정했다.
7. 보행자 회복은 0.25초 지면 안정, 1.35초 자세·anchor 보간, 0.55초 직립 대기 뒤 보행으로
   나눴다. 넘어짐에서 즉시 걷기로 튀던 전환을 줄였지만 최종 모션 캡처 애니메이션은 아니다.
