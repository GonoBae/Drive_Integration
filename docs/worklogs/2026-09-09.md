# 2026-09-09 작업 기록

## 짧은 수신 공백과 근접 장애물 회피

이번 범위는 NPC 표시 깜빡임과 가까운 앞차를 피해 나가지 못하는 문제입니다.
맵·차량 물리·에셋·통신 형식은 변경하지 않습니다.

### 확인한 원인

- Unreal은 마지막 상태 수신 후 100ms를 넘으면 NPC·보행자 Actor와 캐시를 삭제했습니다.
  다음 상태가 도착하면 다시 생성되어, 짧은 공백도 사라졌다 나타나는 현상으로 보였습니다.
  조사한 Play 로그에는 수신 간격 최대 192.4ms가 있었지만, 같은 Play 안에서 WebSocket이
  반복 재연결되었다는 근거와는 구분했습니다.
- 서버의 국소 우회 탐색은 한 NPC만 선택해도 그 NPC의 후보·차체 지면 검사를 한 틱에서
  끝냈습니다. 기존 실행 로그에는 국소 탐색 54.6733ms가 기록되어 있었습니다.
- 후진 전에 후진 완료 위치에서의 전체 우회가 먼저 승인되어야 했습니다. 바로 앞이 막힌
  상황에서 공간을 조금 확보하고 다시 판단하는 행동이 제한되었습니다.

### 변경한 동작

Unreal의 상태 신선도·입력 안전 판정은 기존 100ms를 유지합니다. 이동 예측 기본 상한도
50ms 그대로입니다. 같은 연결·Play·맵에서 100~500ms의 수신 공백이 생기면 마지막으로
표시한 NPC·보행자 위치와 포즈를 동결합니다. 조향·바퀴·운전자·보행자·ragdoll 동작과
경적 재생을 정지하고, 신선한 상태가 도착하면 같은 Actor로 복귀합니다. 실제 연결 종료,
세대·Play·맵 변경, 객체 삭제 및 500ms 초과는 기존처럼 정리합니다. 통신 실패를 무기한
숨기거나 오래된 상태로 차량 제어를 허용하는 변경은 아닙니다.

서버는 우회 후보 내부의 지면·차체 검사와 미래 충돌 검사를 여러 틱으로 나눕니다.
전체 NPC 중 한 대씩 순서대로 처리하며, 한 틱의 국소 탐색은 최대 39 작업,
채택 직전의 현재 경로 검사 9 작업을 합쳐 최대 48 작업입니다. 도로 공간 검색 자료는
맵별로 공유합니다. 이 숫자는 **국소 탐색 작업량 상한**이며 서버 전체 연산 시간이나
전체 지면 조회 횟수의 상한은 아닙니다.

차량이 너무 가까우면 뒤쪽 차체 경로와 여유 공간을 확인하여 0.5m씩 후진합니다.
각 후진 후 다시 우회 가능성을 판단하고, 실행 중에도 매 틱 뒤쪽을 확인합니다.
일반 장애물 6m·사고 장애물 16m의 누적 한도와 도로·충돌·신호 제약은 유지합니다.
뒤가 막혔거나 실제 차체가 통과할 공간이 없으면 기다립니다. 순간 이동이나 제자리 회전은
허용하지 않습니다. 다음 차로의 폐쇄는 국소 우회보다 연결 도로 변경을 먼저 검토합니다.
탐색 도중 장애물이 사라지면 검색·정지 기준과 후진 이력을 해제합니다.

Automation은 무경고 107개·경고 포함 7개입니다. 기존 경고 시험 6개는 그대로이며,

자동 검사와 별도로 Unreal Play에서 짧은 수신 공백의 화면 연속성, 플레이어를 가까이
세웠을 때의 후진·우회, 뒤차가 있는 경우의 대기를 확인해야 합니다. 전체 자율주행 완성이나
30분 주행 안정성 인수를 의미하지 않습니다. 커밋·푸시는 요청 범위에 포함하지 않았습니다.

## 후속: 중앙선을 넘지 않는 NPC 우회

반대편이 비어 있으면 잠시 이용할 수 있던 국소 우회 정책을 제거했습니다.
차량 중심뿐 아니라 회전한 차체의 모서리·측면을 검사합니다. 동방향 차로와 확인된 오른쪽
아스팔트 여유 공간은 사용할 수 있지만, 중앙선 쪽의 미확인 공간과 반대 차로는 사용하지
않습니다. 실제 중앙선과 차로 표본 사이에 틈이 있는 경우도 보수적으로 거절합니다.
통과할 수 없으면 기존의 안전한 짧은 후진·재판단·대기를 따릅니다.

동방향 차로 사이의 작은 간격은 연결하고, 곡선의 선분 이음부는 둥근 끝 영역으로 이어
정상 우회가 중간에서 잘못 정지하지 않도록 했습니다. 실제 곡선 트럭 경로에는 계획 표본
사이를 1cm 간격으로 다시 확인하는 검사를 추가했습니다. 일반 좌회전 경로, 플레이어 물리,
언리얼 표시·에셋과 통신 형식은 변경하지 않았습니다.

- 중앙선 10cm 차체 침범, 빈 반대편만 사용할 수 있는 상황: 동기·분할 탐색 모두 거절.
- Asphalt·LowFriction·Default 판정, 오른쪽 공간과 동방향 3.3m 간격 차로 우회 확인.
- 성공 경로의 회전 차체 네 모서리를 5cm 간격으로 확인. 근접 후진·후방 장애물·실제 곡선
  트럭 통과·일반 경로 및 탐색 예산 회귀 포함 **관련 CTest 9/9 통과**, 103.219초.
  [검사 로그](../../runtime_logs/centerline_20260909/ctest.log),
  [최종 빌드](../../runtime_logs/centerline_20260909/cpp-final-build.log).

이 후속 변경은 서버만 빌드했습니다. 기존 PID 20696을 종료하고 수정본을 **PID 28420,
127.0.0.1:9000**으로 다시 실행하여 리슨 상태를 확인했습니다.
[실행 로그](../../runtime_logs/simcore-signal-city-20260909-010007-bd8df07c.stdout.log).
Play를 다시 시작하면 적용되며, Unreal 재빌드·Bake는 필요하지 않습니다.
